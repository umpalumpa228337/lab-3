# lab-3
# Лабораторная работа №3

## Тема
Работа с файловой системой NTFS и настройка прав доступа к файлам и каталогам.

## Цель работы
Получить практические навыки управления разрешениями NTFS, изучить наследование прав и работу владельцев объектов.

## Краткие теоретические сведения
Файловая система NTFS позволяет ограничивать доступ пользователей к файлам и папкам с помощью специальных разрешений. Права могут назначаться как отдельным пользователям, так и группам. Кроме того, NTFS поддерживает наследование параметров безопасности от родительских каталогов.

Основные разрешения NTFS:
- чтение;
- запись;
- изменение;
- полный доступ.

---

## Выполнение лабораторной работы

Во время выполнения лабораторной работы были созданы папки Temp1, Temp2 и Temp3. Для созданных каталогов были просмотрены параметры безопасности и существующие разрешения пользователей.

Через свойства папок и вкладку «Безопасность» были исследованы группы:
- Administrators;
- Users;
- SYSTEM.

Для группы Administrators были назначены права полного доступа, а для группы Users — права чтения и выполнения.

Также были изучены дополнительные параметры безопасности. В процессе работы было отключено наследование разрешений, после чего система автоматически преобразовала inherited-права в локальные.

Дополнительно была рассмотрена информация о владельце объекта и особенности изменения разрешений при копировании и перемещении каталогов в NTFS.

## Заключение
В ходе выполнения лабораторной работы были изучены механизмы разграничения доступа NTFS, способы изменения разрешений, наследование прав доступа и работа с владельцами файлов и папок.
